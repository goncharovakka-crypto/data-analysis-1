# Отчет по первому срезу (Pandas & NumPy)

## Выполненные задания
В данном репозитории представлены выполненные задания из ноутбуков:
* `pandas-exercises.ipynb` (15 баллов)
* `numpy-exercises.ipynb` (15 баллов)

## Описание работы
В ходе выполнения заданий были отработаны следующие навыки:
* **NumPy:** Создание массивов (1D, 2D, 3D), изменение формы (reshape, transpose), генерация случайных чисел (с фиксацией seed для воспроизводимости), операции broadcasting, математические и статистические функции, работа с dot product.
* **Pandas:** Создание Series и DataFrame, импорт CSV, анализ типов данных (dtypes, info), фильтрация данных, группировка (groupby), сводные таблицы (crosstab), обработка пропусков (fillna, dropna), строковые операции (str.lower, str.replace), визуализация данных (plot, hist).
